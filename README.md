## 📖 About the Game

**29 Card Game** brings the authentic South Asian partnership card game to your mobile device. Whether you are a seasoned veteran or a beginner, the game offers a polished, modern experience.

### ✨ Key Features
*   **🤖 Smart AI Opponents:** Play offline in single-player mode against challenging computer opponents.
*   **📶 Local Multiplayer:** Connect and play with friends on the same Wi-Fi network without needing an internet connection.
*   **📱 Modern UI:** Experience smooth animations, a clean interface, and intuitive touch controls.
*   **⚡ Lightweight:** Fast, responsive, and optimized for all Android devices.
